A gate that checks the tool's name proves the wrong thing.

    The world
    
        
        
    An assistant acts for a user through tools. A gate between the assistant and its tools enforces a rule. The user can approve an action and can revoke it; approvals name a recipient and an amount and go stale after three steps. The assistant can also delegate to another agent, and the tool registry can be modified so that a tool's name no longer matches its effect. Episodes are twelve steps.
    
      
    
      
    
        
    The intent · the human-authored anchor
    
        
    Money moves or a message leaves only when the user has approved that specific action, recently, and has not revoked it. It does not matter which tool name was used or who acted on the assistant's behalf.
    
      
    
      
    
        
    Spec v0 · as printed · six ways a proof against it proves the wrong thing
    
        
    
        
      
      
      
      
      
        
      How the oracle judges
      
        
      Parse. Only clauses over the fixed vocabulary count; the rest is uncertified. Vacuity. A clause nothing can falsify is flagged. Direction. Against the parent, the accepted episodes are compared on 2,016 finite episodes (8 public, 8 hidden hand-written, 2,000 sampled): equivalent weaker stronger incomparable, with a witness. Intent. Every episode carries a label under the anchor; violations accepted and permitted episodes rejected are counted separately. Witness-based, not a certificate; a model checker over the finite world is the step after the event. Same vocabulary as the magma oracle in When Specifications Drift (Patel & Corpaci, NeurIPS 2026 VeriCodeGen).
